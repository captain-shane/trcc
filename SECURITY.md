# Security Policy

## Supported versions

Security fixes are applied to the tip of `main` and the most recent release
only. Older releases do not receive backported fixes.

## Reporting a vulnerability

Please **do not open a public issue** for anything security-sensitive.

- **Preferred:** use GitHub private vulnerability reporting — the
  **Security** tab of this repository → **Report a vulnerability**.
- **Alternative:** email `captain+github@thecloudpirates.life` with a
  description of the issue, steps to reproduce, and the affected
  version/commit.

You will receive an acknowledgement within 72 hours. Please allow a
reasonable disclosure window for a fix to be prepared and released before
any public write-up.

## Scope

Anything in this repository is in scope. Vulnerabilities in third-party
dependencies should be reported upstream, but a heads-up here is welcome if
this project's usage makes the impact worse.
